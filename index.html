Screen coverage

Penerapan token pada halaman FDS

Tabel ini menunjukkan token yang dominan pada setiap tipe halaman, bukan definisi baru.

Page family Dominant components Typography emphasis Special rule
Transactions / Case Management lists Page title, summary metric, filter label, table header, primary/secondary cells, pagination text-3xl, text-sm, text-xs Score, amount, SLA, and timestamps use tabular numbers.
Transaction / Case detail Entity title, badges, key-value strip, tabs, detail cards, score tables text-4xl for entity ID Do not shrink IDs to fit; allow responsive wrap on smaller screens.
Rule Configuration / Profile Group Page title, metadata, tabs, section title, formula, assigned-rule table, scope chips text-sm/6 for technical formulas Keep operators, field names, and numeric thresholds in JetBrains Mono.
Approval / Draft workflow Section title, description, workflow badge, reviewer table, timestamps Weight and colour communicate status Status labels remain 12 px across all states.
Danger Zone Card title, warning body, status badge, destructive button Same hierarchy, red semantic colour Do not use larger font merely to signal danger.
Add Role / Configuration forms Compact page title, field label, input value, helper text, table permission matrix text-2xl, text-sm, text-xs Minimum supporting text is 12 px.
Activity Log / Audit Log Timeline title, actor/time metadata, event description, SLA metrics Clear separation between event, metadata, and detail Use tabular numbers for duration and time.
Reports Page title, hero metric, KPI cards, chart titles, legends, report table text-4xl only for hero metrics Legend and chart metadata stay at 12 px.

Implementation

Tailwind setup dan semantic component classes

Gunakan utility langsung pada komponen atau rangkum dengan semantic classes menggunakan @apply.

Tailwind theme

@import "tailwindcss";

@theme {
  --font-fds: "JetBrains Mono", ui-monospace,
    SFMono-Regular, Menlo, Monaco, Consolas, monospace;
}

.fds-number {
  font-variant-numeric: tabular-nums;
}

Semantic classes

@layer components {
  .fds-page-title { @apply text-3xl/9 font-bold; }
  .fds-entity-title { @apply text-4xl/10 font-bold; }
  .fds-section-title { @apply text-xl/7 font-semibold; }
  .fds-card-title { @apply text-lg/7 font-semibold; }
  .fds-body { @apply text-sm/5 font-normal; }
  .fds-control { @apply text-sm/5 font-semibold; }
  .fds-meta { @apply text-xs/5 font-normal; }
  .fds-table-head { @apply text-xs/4 font-semibold uppercase tracking-wide; }
  .fds-badge { @apply text-xs/4 font-semibold uppercase; }
}

Final recommendation

Gunakan text-sm sebagai ukuran utama antarmuka dan text-xs sebagai ukuran compact. Ukuran yang lebih besar hanya dipakai untuk hierarchy, entity identifier, dan metrics. Jangan membuat token baru berdasarkan halaman; buat token berdasarkan fungsi komponen.
